## 🚀 CARA SETUP (3 Langkah Mudah)

### Langkah 1: Download File
```
1. Copy file ai-chat.html ke komputer Anda
2. Atau buat file baru dengan nama ai-chat.html
3. Copy-paste seluruh kode ke dalamnya
```

### Langkah 2: Dapatkan API Key Gratis
Lihat bagian [Mendapatkan API Key](#mendapatkan-api-key) di bawah

### Langkah 3: Setup API Key di File
```
1. Buka ai-chat.html dengan text editor (Notepad++, VS Code, dll)
2. Cari baris: const API_KEY = 'sk-ant-';
3. Ganti dengan API key Anda:
   const API_KEY = 'sk-ant-xxxxxxxxxxxxxxxx';
4. Simpan file (Ctrl + S)
```

### Langkah 4: Buka di Browser
```
1. Double-click file ai-chat.html
2. Atau drag file ke browser
3. Atau buka browser → File → Open → pilih ai-chat.html
```

**Selesai!** App sudah siap digunakan! 🎉

## 🐛 TROUBLESHOOTING

### Error: "API Error 401"
**Penyebab:** API key salah atau expired
**Solusi:**
1. Cek API key di console.anthropic.com
2. Copy ulang dengan hati-hati (ada space?)
3. Pastikan benar di baris: `const API_KEY = 'sk-ant-...'`

### Error: "API Error 429"
**Penyebab:** Rate limit (terlalu banyak request)
**Solusi:**
1. Tunggu 1-2 menit
2. Mulai ulang browser
3. Gunakan model yang lebih cepat (Haiku)

### Error: "CORS Error"
**Penyebab:** Browser block request
**Solusi:**
1. Buka browser console (F12)
2. Periksa error detail
3. Pastikan API_KEY benar
4. Coba browser lain

### Chat tidak tersimpan
**Penyebab:** Local storage disabled
**Solusi:**
1. Enable local storage di browser
2. Settings → Privacy → Allow cookies
3. Bukan mode incognito/private

### Suara tidak jalan
**Penyebab:** Browser tidak support speech
**Solusi:**
1. Gunakan Chrome/Edge (paling support)
2. Atau ketik manual
3. Izinkan akses microphone

### Response lambat
**Penyebab:** Koneksi internet lambat
**Solusi:**
1. Cek kecepatan internet
2. Gunakan model Haiku (lebih cepat)
3. Kurangi max_tokens
